# Changelog

## [1.0.0] 

### Added
- SQLite database with five related tables and sample data.
- Product management and search functionality.
- Four inventory and sales reports.
- Atomic stock adjustments and sales transactions.
- Interactive terminal menu with input validation.
- SQLite database backup.
- Docker container with persistent database storage.
- Automated tests and GitHub Actions CI.

## [1.1.0] 

### Added
- Dynamic low-stock alert on the main menu.
- Automatic recalculation of low-stock product counts after inventory changes.
